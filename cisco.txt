!Part 2 – Configure Remote Access (SSH)
!Step 1: Configure a hostname and domain name
En
Config t
hostname R1
ip domain-name cisco.com
!Step 2: Create a user account
username admin privilege 15 secret cisco
!Step 3: Generate RSA keys for SSH
crypto key generate rsa
!  			(choose 1024 or 2048 bits)
!Step 4: Enable SSH on vty lines
ip ssh version 2
line vty 0 4
login local
transport input ssh
exit
!Step 5: Save configuration
write memory
!👉 Repeat same steps on R2, adjusting hostname if needed.
